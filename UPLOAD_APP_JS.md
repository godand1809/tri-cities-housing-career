# Important: add `app.js`

The main application logic lives in **`app.js`** (about 41 KB).

Because of size limits on automated upload, download the release zip from the chat (or the files provided with this project) and upload **`app.js`** into this repository root:

1. Open https://github.com/godand1809/tri-cities-housing-career
2. Click **Add file → Upload files**
3. Drop in `app.js` from the zip
4. Commit to `main`

After that, open `index.html` (or enable GitHub Pages) and the full app will run.

Files that should be in the repo root:

- `index.html`
- `app.js`
- `sw.js`
- `manifest.webmanifest`
- `README.md`
- `LICENSE`
