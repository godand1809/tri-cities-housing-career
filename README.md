# Tri-Cities Housing & Career Assistant

Mobile-first, offline-capable web app for tracking **housing applications**, **job leads**, and **documents** in Benton & Franklin Counties (Kennewick, Pasco, Richland, and nearby).

All data is stored in your browser’s **localStorage**. Nothing is sent to a server.

## Features

- **Dashboard** — progress stats, next actions, quick-dial contacts
- **Housing tracker** — Kennewick HA, Pasco HA, Coordinated Entry / CAC, shelters, utility help, and more
- **Job tracker** — Benton PUD, PNNL, Ben Franklin Transit, Energy Northwest, Hanford-area employers, WorkSource, cities & counties
- **Checklist** — documents, income, housing, and job prep items
- **Profile** — name, contact, household, situation
- **Zero-Income Statement** — generate, copy, or print a worksheet from your profile
- **Copy task list** — formatted list for Google Tasks or notes
- **Dark mode** — respects system preference; toggle in the header
- **Offline** — service worker caches the app after first load
- **Import / export** — JSON backup of your data

## Open on your phone

1. Clone or download this repo.
2. Open `index.html` in Chrome or Samsung Internet (or host the folder on any static host / GitHub Pages).
3. Optional: **Add to Home screen** for an app-like icon.

### GitHub Pages

1. Repo **Settings → Pages**
2. Source: Deploy from branch `main`, folder `/ (root)`
3. Open `https://<your-username>.github.io/tri-cities-housing-career/`

## Disclaimer

Phone numbers, hours, and program status change. Always **call agencies to confirm** waitlists, intake, and required forms. This app is a personal organizer, not legal advice and not an official government service.

Crisis resources: **911** (emergency) · **988** (suicide & crisis) · **2-1-1** (community resources) · DV crisis line in-app under Housing.
